# Éditeur PDF

Éditeur PDF de bureau basé sur PySide6 et PyMuPDF.

## Prérequis

- Python 3.10+

## Installation

```bash
pip install PySide6 PyMuPDF
```

## Lancement

```bash
python main.py
```

## Compilation en exécutable (.exe)

```bash
pip install pyinstaller
pyinstaller EditeurPDF.spec
```

L'exécutable sera généré dans `dist/EditeurPDF/EditeurPDF.exe`.
